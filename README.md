# Hand-Tracking-Robotic-Hand
This the code for the hand tracking part of my robotic hand. This enables my robotic hand to mimic my hand movements using libraries such as Open-CV and Mediapipe.
I got a bit of help from ChatGPT because I was completely new to the libraries used and unfamiliar with the functions. 
The files are a bit messy as I was testing out different stuff that ChatGPT informed me about to learn and see how it works.
The main file is the handtracking_in_action.py
I hope you can take inspiration from this and that you like it!
